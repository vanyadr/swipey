# Swipey

React + TypeScript + Vite. Веб-приложение для выбора кино вдвоём. Основной экран соответствует макету Figma: цвет #73a66e, шрифт Dela Gothic One, размеры 402 × 874.

## Запуск

```bash
npm install
npm run dev
npm run build
```

## Сценарии

1. Введите имя и нажмите «Начать».
2. Пройдите 15 карточек, свайпами или кнопками. Доступна отмена последнего выбора.
3. Сканируйте QR вторым телефоном, скопируйте ссылку или нажмите «Продолжить на этом телефоне».
4. Введите имя второго игрока, оцените 15 фильмов.
5. Просмотрите совпадения и личные результаты.

## Важные замечания

- Данные передаются в URL-фрагменте, без сервера. Общий результат отображается на устройстве второго игрока.
- В исходном Figma был только один реальный кинопостер («Шрек 2»). Остальные 14 постеров пока заменены стилизованными карточками, до предоставления подтвержденных источников изображений.
- Для работы камеры в браузере требуется HTTPS или localhost.
- Точная пиксельная сверка и сборка зависят от установки зависимостей.
